# ย้าย Backend มาที่ Cloudflare Workers + D1 (ฉบับมือใหม่)

คู่มือนี้พาคุณย้ายจาก Google Apps Script + Sheets มาที่ **Cloudflare Workers + D1**
ซึ่ง **เร็วและเสถียรกว่ามาก** รองรับนักเรียนหลายสิบคนสอบพร้อมกันสบาย ๆ และ **ฟรี**

> ทำผ่านหน้าเว็บ Cloudflare Dashboard ทั้งหมด **ไม่ต้องใช้ command line** (มีวิธี CLI อยู่ท้ายไฟล์)
> เวอร์ชันนี้ **ยังไม่รองรับรูปภาพในข้อสอบ** (ข้อสอบตัวหนังสือ/สมการใช้ได้เต็มที่) — เพิ่มภายหลังได้

ไฟล์ที่ใช้ในโฟลเดอร์นี้: [`schema.sql`](schema.sql) (โครงฐานข้อมูล) และ [`worker.js`](worker.js) (โค้ด Backend)

---

## ทำไมต้องย้าย
| | Google Sheets + GAS | Cloudflare Workers + D1 |
|---|---|---|
| ความเร็ว | ช้า (cold start ~1-3 วิ) | เร็วมาก (~50ms, ไม่มี cold start) |
| หลายคนพร้อมกัน | ต่อคิว/timeout ได้ | รองรับได้ดี (ฐานข้อมูลจริง) |
| ค่าใช้จ่าย | ฟรี | ฟรี (100k req/วัน, D1 5GB) |

---

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ~15 นาที)

### 1) สมัคร Cloudflare (ฟรี)
ไปที่ [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) สมัครด้วยอีเมล (ไม่ต้องใส่บัตรเครดิต)

### 2) สร้างฐานข้อมูล D1
1. ในหน้า Dashboard เมนูซ้าย เลือก **Storage & Databases → D1 SQL Database**
2. กด **Create** → ตั้งชื่อ `exam-db` → **Create**

### 3) สร้างตารางฐานข้อมูล — เลือกวิธีใดวิธีหนึ่ง

**วิธี ก (ง่ายสุด แนะนำ): ใช้คำสั่ง initDb**
> ทำหลังจากทำขั้นตอน 4–5 (สร้าง Worker + ผูก D1) เสร็จแล้ว โดยเปิดเบราว์เซอร์ไปที่:
> ```
> https://exam-api.xxxx.workers.dev/?action=initDb
> ```
> ถ้าได้ผล `{"ok":true,"data":{"initialized":true,...}}` = สร้างตารางครบแล้ว (เรียกซ้ำได้ ไม่ลบข้อมูลเดิม)

**วิธี ข: รัน schema.sql เองใน Console**
1. เปิดฐานข้อมูล `exam-db` → แท็บ **Console**
2. เปิดไฟล์ [`schema.sql`](schema.sql) **คัดลอกทั้งหมด** มาวาง → **Execute**
3. จะได้ตารางครบ 9 ตาราง + รายวิชาพื้นฐาน 8 วิชา

> **สำคัญ:** ต้องสร้างตารางในฐานข้อมูลตัวเดียวกับที่ผูก binding `DB` ไว้ (ขั้นตอน 5)
> ถ้าเจอ error `no such table` แปลว่ายังไม่ได้ทำขั้นตอนนี้ หรือทำผิดฐานข้อมูล

### 4) สร้าง Worker และวางโค้ด
1. เมนูซ้าย เลือก **Compute (Workers) → Workers & Pages**
2. กด **Create** → **Start with Hello World** (หรือ Create Worker) → ตั้งชื่อ เช่น `exam-api` → **Deploy**
3. กด **Edit code** (หรือ **</> Edit**)
4. ลบโค้ดตัวอย่างในหน้าแก้ไขออกให้หมด
5. เปิดไฟล์ [`worker.js`](worker.js) **คัดลอกทั้งหมด** มาวางแทน
6. กด **Deploy** (มุมขวาบน)

### 5) ผูกฐานข้อมูลและตั้งรหัสครู (Bindings & Variables)
1. กลับไปหน้า Worker `exam-api` → แท็บ **Settings**
2. หัวข้อ **Bindings** → **Add** → เลือก **D1 database**
   - **Variable name:** `DB`  *(ต้องเป็น DB ตัวใหญ่ทั้งหมด)*
   - **D1 database:** เลือก `exam-db`
   - **Save**
3. หัวข้อ **Variables and Secrets** → **Add**
   - **Name:** `TEACHER_CODE`
   - **Value:** `127` *(หรือรหัสครูที่คุณต้องการ — แนะนำให้ตั้งเป็นเลข/ตัวอักษรที่เดายาก)*
   - เลือกชนิดเป็น **Secret** ถ้ามีให้เลือก (ปลอดภัยกว่า) → **Save/Deploy**

> หลังเพิ่ม Bindings แล้ว ให้กด **Deploy** อีกครั้งเพื่อให้มีผล

### 6) คัดลอก URL ของ Worker
ที่หน้า Worker จะเห็น URL ประมาณ:
```
https://exam-api.<ชื่อบัญชีของคุณ>.workers.dev
```
**คัดลอกไว้** — นี่คือ URL ที่จะใช้แทน GAS_URL

### 7) เปลี่ยน URL ในหน้าเว็บ
1. เปิดไฟล์ `js/config.js` (ในโปรเจกต์หลัก)
2. เปลี่ยนค่า `GAS_URL` เป็น URL ของ Worker:
   ```js
   const CONFIG = {
     GAS_URL: 'https://exam-api.xxxx.workers.dev',
     ...
   };
   ```
   > ไม่ต้องแก้อย่างอื่นเลย — Worker รับ-ส่งข้อมูลรูปแบบเดียวกับ GAS ทุกอย่าง
3. บันทึก แล้ว **push ขึ้น GitHub** (GitHub Actions จะ deploy ให้อัตโนมัติ)

### 8) ทดสอบ
- เปิดเว็บ → เข้าครูด้วยรหัสที่ตั้งไว้ → เพิ่มห้องเรียน + นำเข้ารายชื่อนักเรียน (CSV) + สร้าง/นำเข้าข้อสอบ → เปิดสอบ
- ลองเข้าเป็นนักเรียนแล้วทำข้อสอบ

**ตรวจ Worker ทำงานไหม:** เปิด URL ของ Worker ต่อท้ายด้วย `/?action=ping` ในเบราว์เซอร์
ควรได้ผล `{"ok":true,"data":{"time":"...","version":"1.0-cf"}}`

## เริ่มข้อมูลใหม่ (ตามที่เลือกไว้)
ระบบนี้เริ่มด้วยฐานข้อมูลเปล่า + รายวิชาพื้นฐาน คุณกรอกข้อมูลใหม่ได้เลย:
- **นักเรียน:** เมนูนักเรียน → นำเข้า CSV (เร็วสุด) หรือเพิ่มทีละคน
- **ข้อสอบ:** เมนูนำเข้าข้อสอบ → วางจาก Word แล้วบันทึก

---

## ปัญหาที่พบบ่อย
- **หน้าเว็บขึ้น error เชื่อมต่อไม่ได้:** ตรวจว่า `GAS_URL` ใน config.js เป็น URL ของ Worker ที่ถูกต้อง และ push ขึ้น GitHub แล้ว
- **error เกี่ยวกับ DB / "no such table":** ยังไม่ได้รัน `schema.sql` (ขั้นตอน 3) หรือยังไม่ได้ผูก binding ชื่อ `DB` (ขั้นตอน 5)
- **รหัสครูไม่ผ่าน:** ตรวจค่า `TEACHER_CODE` ในแท็บ Settings ของ Worker แล้วกด Deploy ใหม่
- **แก้โค้ด worker แล้วไม่มีผล:** ต้องกด **Deploy** ทุกครั้งหลังแก้

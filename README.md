# ระบบสอบออนไลน์สำหรับโรงเรียน (Online Examination System)

ระบบสอบออนไลน์ที่ใช้งาน **ฟรี 100%** สำหรับโรงเรียนประถมศึกษา
สร้างด้วย **HTML + CSS + JavaScript** โฮสต์บน **GitHub Pages**
ใช้ **Google Apps Script** เป็น Backend และ **Google Sheets** เป็นฐานข้อมูล

> ไม่ต้องเช่า Server • ไม่มีค่าใช้จ่ายรายเดือน • รองรับนักเรียน 30–100 คนสอบพร้อมกัน

---

## ✨ คุณสมบัติหลัก

- 🧑‍🎓 นักเรียนเข้าสอบด้วย **รหัสนักเรียน** (ไม่ต้องตั้งรหัสผ่าน)
- 🔐 ครูเข้าระบบด้วยรหัสลับ (เก็บใน Backend ไม่อยู่ในหน้าเว็บ)
- 📝 สร้าง/แก้ไขข้อสอบ, **นำเข้าข้อสอบจาก Word** (วางแล้วแยกอัตโนมัติ ใช้ `*` ระบุคำตอบ)
- ➗ รองรับ **สมการคณิตศาสตร์** (MathJax) และ **รูปภาพ** (เก็บใน Google Drive)
- ⏱️ จับเวลา + ส่งอัตโนมัติเมื่อหมดเวลา + กันข้อมูลหายเมื่อ Refresh (localStorage)
- 📊 Dashboard: สรุปคะแนน, ตารางผลสอบ (เรียง/ค้นหาได้), **วิเคราะห์ข้อสอบรายข้อ**
- ⬇️ Export CSV / Excel / พิมพ์รายงาน
- 📱 Responsive รองรับคอมพิวเตอร์ แท็บเล็ต โทรศัพท์ — ภาษาไทยทั้งหมด

## 🏗️ สถาปัตยกรรม

```
[GitHub Pages]  ── fetch (text/plain) ──►  [Google Apps Script Web App]  ──►  [Google Sheets]
   HTML/CSS/JS                                  API (ตรวจคะแนน/สิทธิ์)              ฐานข้อมูล
                                                       │
                                                       └──►  [Google Drive]  (เก็บรูปภาพ)
```

**หลักการลดภาระ/ลด Request (สำคัญ):**
- เปิดข้อสอบ → โหลดข้อมูล **ครั้งเดียว** (ไม่มีเฉลยติดมา)
- ทำข้อสอบ → คำตอบเก็บใน **localStorage** ของเบราว์เซอร์ (ไม่ยิง Server ทุกคลิก)
- กดส่ง → ส่งคำตอบทั้งหมด **ครั้งเดียว** → Server ตรวจคะแนน + ใช้ `LockService` กันเขียนชนกัน
- ตรวจคำตอบ/สิทธิ์/เวลา/กันส่งซ้ำ ทำที่ **Server** เสมอ

## 🚀 การติดตั้ง (ทำตามทีละขั้น)

### 1) สร้าง Google Sheet
1. ไปที่ [sheets.google.com](https://sheets.google.com) → สร้างสเปรดชีตใหม่
2. ตั้งชื่อ เช่น `ฐานข้อมูลข้อสอบ`
3. คัดลอก **Spreadsheet ID** จาก URL (ส่วนระหว่าง `/d/` กับ `/edit`)
   ```
   https://docs.google.com/spreadsheets/d/  1AbCdEf...XyZ  /edit
                                            └── นี่คือ Spreadsheet ID ──┘
   ```

### 2) สร้าง Google Apps Script
1. ในสเปรดชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดตัวอย่างที่มีอยู่ออก

### 3) วางโค้ด Backend
1. สร้างไฟล์ตามในโฟลเดอร์ [`gas/`](gas/) ให้ครบ (กด **＋ → Script** เพื่อเพิ่มไฟล์):
   `Code.gs · Config.gs · Auth.gs · Students.gs · Exams.gs · Questions.gs · Results.gs · Utils.gs`
2. คัดลอกเนื้อหาแต่ละไฟล์จากโฟลเดอร์ `gas/` มาวางให้ตรงชื่อ
3. กด **บันทึก** (💾)

### 4) ตั้งค่า Spreadsheet ID
1. ในหน้า Apps Script ไปที่ **⚙️ Project Settings → Script Properties**
2. เพิ่ม property:
   - Key: `SPREADSHEET_ID`  ·  Value: *(Spreadsheet ID จากข้อ 1)*
   - (ไม่บังคับ) Key: `TEACHER_CODE` · Value: `127` — ถ้าไม่ตั้ง ระบบใช้ `127` เป็นค่าเริ่มต้น

> **หมายเหตุ:** ถ้าคุณเปิด Apps Script ผ่านเมนู "ส่วนขยาย" ของชีตอยู่แล้ว จะข้ามการตั้ง `SPREADSHEET_ID` ก็ได้ (สคริปต์จะผูกกับชีตนั้นอัตโนมัติ) แต่แนะนำให้ตั้งไว้เพื่อความชัวร์

### 5) ติดตั้งฐานข้อมูล (รันครั้งเดียว)
1. ที่แถบด้านบน เลือกฟังก์ชัน **`setupSpreadsheet`** แล้วกด **▶️ Run**
2. อนุญาตสิทธิ์ (Authorize) เมื่อระบบถาม → เลือกบัญชี → *Advanced* → *Go to project (unsafe)* → *Allow*
   - ระบบจะขอสิทธิ์เข้าถึง Sheets และ Drive (สำหรับเก็บรูป) — เป็นเรื่องปกติ
3. เมื่อรันเสร็จ ชีตทั้ง 9 แผ่นจะถูกสร้างพร้อมหัวตาราง + รายวิชาพื้นฐาน
4. (ไม่บังคับ) รัน **`seedSampleData`** เพื่อใส่นักเรียน/ห้องตัวอย่างสำหรับทดสอบ

### 6) Deploy เป็น Web App
1. กด **Deploy → New deployment**
2. เลือกประเภท (⚙️) เป็น **Web app**
3. ตั้งค่า:
   - **Execute as:** `Me` (บัญชีของคุณ)
   - **Who has access:** `Anyone` *(สำคัญ! ต้องเป็น Anyone เพื่อให้นักเรียนเรียกได้)*
4. กด **Deploy** → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

> ทุกครั้งที่แก้โค้ด `.gs` ต้อง **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** เพื่อให้เวอร์ชันใหม่มีผล

### 7) นำ Web App URL มาใส่ในหน้าเว็บ
1. เปิดไฟล์ [`js/config.js`](js/config.js)
2. วาง URL ที่ได้ลงในช่อง `GAS_URL`
   ```js
   const CONFIG = {
     GAS_URL: 'https://script.google.com/macros/s/AKfy...../exec',
     SCHOOL_NAME: 'โรงเรียนของคุณ',
     ...
   };
   ```

### 8) เปิด GitHub Pages
1. นำโค้ดทั้งหมดขึ้น GitHub Repository (push)
2. ไปที่ **Settings → Pages**
3. Source: `Deploy from a branch` → Branch: `main` → Folder: `/ (root)` → **Save**
4. รอสักครู่ จะได้ลิงก์ เช่น `https://ชื่อผู้ใช้.github.io/online-exam/`

### 9) ทดสอบระบบ
- เปิดลิงก์ GitHub Pages → หน้า Login นักเรียน
- คลิก "สำหรับครู" → ใส่รหัส `127` → เข้าสู่ Dashboard
- ลองเพิ่มนักเรียน สร้างข้อสอบ เปิดสอบ แล้วทดลองทำในฐานะนักเรียน

## 📖 วิธีใช้งาน

### 10) วิธีเพิ่มนักเรียน
- เมนู **นักเรียน → ＋ เพิ่มนักเรียน** (ทีละคน) หรือ **📥 นำเข้า CSV** (จำนวนมาก)
- รูปแบบ CSV: `รหัส, คำนำหน้า, ชื่อ-นามสกุล, ชั้น, ห้อง, เลขที่`
  (เว้นรหัสว่างได้ ระบบจะสร้างเลข `S0001, S0002, ...` ให้อัตโนมัติ)
- สร้าง **ห้องเรียน** ที่เมนู "ห้องเรียน" ก่อน เพื่อให้เลือกชั้น/ห้องได้สะดวก

### 11) วิธีสร้างข้อสอบ
1. เมนู **ข้อสอบ → ＋ สร้างข้อสอบใหม่**
2. กรอกชื่อชุด, วิชา, ระดับชั้น, เวลาทำ, คะแนนต่อข้อ ฯลฯ
3. เพิ่มคำถาม/ตัวเลือก, เลือกวงกลมหน้าคำตอบที่ถูก, แนบรูปได้
4. กด **💾 บันทึกข้อสอบ**
5. ที่ตารางข้อสอบ กดปุ่ม **🟢 เปิด** เพื่อเปิดสอบ (นักเรียนที่ตรงชั้น/ห้องจะเห็น)

### 12) วิธีนำเข้าข้อสอบจาก Word
1. เมนู **นำเข้าข้อสอบ**
2. คัดลอกข้อสอบจาก Word มาวาง — ใส่ `*` หน้าตัวเลือกที่เป็นคำตอบที่ถูก:
   ```
   1. ข้อใดเป็นการเปลี่ยนแปลงทางเคมี
   ก. น้ำแข็งละลาย
   ข. น้ำเดือด
   *ค. เหล็กเกิดสนิม
   ง. น้ำตาลละลายน้ำ

   2. 25 × 4 มีค่าเท่าใด
   ก. 50
   *ข. 100
   ค. 125
   ง. 150
   ```
3. กด **🔍 วิเคราะห์** → ตรวจสอบ Preview → **➡️ ไปตั้งค่าและแก้ไขข้อสอบ**
4. ปรับแต่ง/ตั้งค่าเพิ่มเติม แล้ว **บันทึกข้อสอบ**

**รูปแบบตัวเลือกที่รองรับ:** `ก. ข. ค. ง.` · `A. B. C. D.` · `1. 2. 3. 4.` · `ก) ข) ค) ง)`
**สมการคณิตศาสตร์:** พิมพ์แบบ LaTeX คร่อมด้วย `$...$` เช่น `$\frac{3}{4}+\frac{1}{2}$`, `$x^2+2x+1$` (เลขยกกำลัง/เศษส่วนแบบยูนิโคดจาก Word ใช้ได้เลย)

## 🔒 ความปลอดภัยและข้อจำกัด

- **รหัสครูไม่อยู่ในหน้าเว็บ** — ตรวจสอบที่ Backend เท่านั้น (Script Properties)
- **ไม่ส่งเฉลยไปเบราว์เซอร์ก่อนสอบ** — Server ตรวจคะแนนเอง แล้วค่อยส่งผล
- Server ตรวจซ้ำทุกครั้ง: สิทธิ์เข้าสอบ · ข้อสอบเปิดอยู่ · ช่วงเวลา · กันส่งซ้ำ · คะแนนไม่เกินเต็ม
- **หมายเหตุเรื่องเวลา:** นาฬิกาจับเวลาอิงเบราว์เซอร์ และ Server บันทึกเวลาที่ใช้จริงไว้ตรวจสอบ
  ระบบนี้ออกแบบเพื่อการสอบในห้องเรียนที่มีครูคุมสอบ ไม่ใช่การสอบแข่งขันระดับสูง

**Quota ฟรีของ Google Apps Script** (โดยประมาณต่อวัน): เรียกได้ ~20,000 ครั้ง, สคริปต์รันได้ 6 นาที/ครั้ง
ระบบออกแบบมาให้แต่ละการสอบใช้เพียง ~2 request (โหลด + ส่ง) จึงรองรับการใช้งานจริงได้สบาย
